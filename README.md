## 🔥 Key Pentesting Features

* 📻 **Extended Sub-1 GHz RF Lab:** Capture, analyze, and replay RF signals (315, 433 MHz). Features an external SMA port allowing for a 250m RF range—up to 3x the distance of standard pentesting hardware.
* 📡 **Comprehensive Protocol Suite:** Full support for **NFC** (13.56 MHz Mifare) and **RFID** (125 kHz EM, HID) access control testing and cloning.
* 📺 **Infrared (IR):** Built-in IR TX/RX (800-950nm) for controlling TVs, IoT appliances, and experimenting with universal IR protocols.
* 🔐 **Advanced Security Research:** Deep support for **KeeLoq** hopping code analysis and **U2F** (FIDO/Passwordless) hardware authentication protocols.
* 🔓 **Architectural Parity:** 100% compatible with the open-source Flipper Zero ecosystem. Run custom firmwares, community plugins, and third-party modules seamlessly.
* 📟 **1.37" Monochrome LCD:** Crisp, clear, real-time feedback and intuitive menu interaction directly on the device.

## 🛠️ Quick Start Guide

1. **Connect:** Plug the SHARK PRO into your computer using a USB-C cable or insert a microSD card (up to 256GB).
2. **Flash:** Load custom community firmwares perfectly adapted for the STM32 microcontroller core.
3. **Execute:** Navigate the built-in UI to run RF penetration tests, blast IR signals, read NFC/RFID access tags, or authenticate via U2F.
4. **Customize:** Utilize the 5V / 3.3V GPIO expansion pins to add your own external modules, custom sensors, and hardware addons.
